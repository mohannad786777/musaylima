## ✨ المميزات

- 🔍 **بحث فوري** في جميع التفريغات النصية
- 📺 **مشاهدة مدمجة** مع انتقال تلقائي للوقت المحدد
- 📱 **تطبيق PWA** يعمل بدون إنترنت
- 🎨 **واجهة عربية** بتصميم عصري
- ⚡ **أداء سريع** بدون خوادم خارجية

## 🚀 التثبيت المحلي

```bash
# استنساخ المشروع
git clone https://github.com/mohannad786777/musaylima.git
cd musaylima

# فتح في المتصفح مباشرة
# أو استخدام خادم محلي
npx serve .
```

## 📁 هيكل المشروع

```
musaylima/
├── index.html      # الصفحة الرئيسية (HTML + CSS + JS)
├── data.json       # قاعدة بيانات الحلقات والتفريغات
├── sw.js           # Service Worker للعمل بدون إنترنت
├── manifest.json   # إعدادات PWA
├── musaylima.jpeg  # شعار التطبيق
├── icon-192.png    # أيقونة PWA (192x192)
└── icon-512.png    # أيقونة PWA (512x512)
```

## 🔌 خادم MCP للذكاء الاصطناعي

يمكن ربط الأرشيف بـ Claude أو ChatGPT أو Cursor ليبحث فيه مباشرة. التفاصيل في [`mcp-server/README.md`](mcp-server/README.md).

## 🛠️ التقنيات المستخدمة

- **HTML5** / **CSS3** / **JavaScript** (Vanilla)
- **PWA** (Progressive Web App)
- **Service Worker** للتخزين المؤقت
- **YouTube IFrame API** لتشغيل الفيديو

## 📊 الإحصائيات

- 📹 أكثر من **2000+ حلقة** مفهرسة
- 📝 آلاف المقاطع النصية قابلة للبحث
- ⏱️ انتقال مباشر لأي لحظة في الفيديو

هذا المشروع للاستخدام التعليمي والبحثي. جميع حقوق المحتوى محفوظة لأصحابها.
